## 6. 관리 원칙

- 현재 코드에서 실행해 확인한 명령만 기록합니다.
- 테스트 개수와 통과 결과에는 확인 날짜 또는 기준 커밋을 함께 기록합니다.

- 테스트 구조가 변경되면 이 문서의 구조와 실행 명령도 함께 갱신합니다.
