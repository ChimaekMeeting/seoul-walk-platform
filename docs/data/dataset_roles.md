## 상태 기준

| 상태 | 의미 |
|---|---|
| 활성 | V1 기본 실행에서 Layer·Score·POI 또는 Graph를 만든다. |
| 제한 활성 | 확인된 위치에만 가점·주의를 적용하며 미제공 지역을 감점하지 않는다. |
| 후보 Layer | 검증 후보를 저장하지만 WalkEdge Tag로 자동 확정하지 않는다. |
| 검증 전용 | 품질 확인에만 사용하고 런타임 DB에 넣지 않는다. |
| 보류 | 필요한 형상·의미가 부족해 경로 계산에 사용하지 않는다. |
| 제외 | V1 입력으로 사용하지 않는다. |

## 공통 처리 기준

- 좌표·숫자 결측을 `0`으로 채우지 않는다.
- 원본 오류는 주소·시설 ID처럼 재현 가능한 근거가 있을 때만 정정한다.
- 동일 위치는 중복 가점을 막되 서로 다른 시설 원본은 보존한다.
- 일부 구에만 있는 데이터는 확인된 위치에만 가점한다.
- Point는 새 WalkNode가 아니라 기존 WalkEdge와의 관계로 저장한다.
- 유효하지 않은 Line을 좌표 순서만으로 임의 복원하지 않는다.

## 알고리즘 입력 결정

- `convenience`: 상권과 연결된 화장실·대중교통의 제한 가점
- `accessibility`: 연결된 엘리베이터·리프트의 제한 가점
- `park_overlap_ratio`: 공원 내부 Edge의 자연 가점
- `is_vehicle_caution`: 어린이보호구역 주변 차량 주의 페널티
- 터널·육교·지하철망·건물 내부: 완전 차단이 아닌 쾌적도 페널티
- `blocked_tags`: 검증된 실제 WalkEdge Tag에만 적용
