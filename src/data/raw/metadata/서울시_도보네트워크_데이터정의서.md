## 품질상 주의점

### 은평구 고가도로 플래그

고가도로 2,831개 중 2,623개가 은평구에 집중되어 있고 실제 고가도로가 아닌 좌표가 포함된 것으로 조사됐다. 은평구의 고가도로 플래그는 V1 점수의 신뢰 가능한 주지표로 사용하지 않는다.

### 산 주변 네트워크 부족

산 주변 일부 지역은 NODE와 LINK가 부족하다. 서비스 범위와 둘레길·탐방로 추가 여부를 별도로 결정해야 한다.

## V1 적재 시 필수 판정

1. NODE 행을 우선 사용해 `walk_nodes`를 생성한다.
2. NODE가 없는 링크 끝점은 LINK WKT로 보완한다.
3. LINK 유형 코드를 4자리 문자열로 보존하고 통행 주체별 boolean으로 파싱한다.
4. 첫 자리가 `0`인 253개 LINK는 `is_walkable=false`로 저장한다.
5. 실제 라우팅용 NetworkX 그래프에서는 보행 불가 LINK를 제외한다.
6. LINK 플래그는 `walk_edges`에 저장하고 NetworkX edge 태그로 전달한다.
7. NODE의 육교·횡단보도 플래그와 NODE 유형 코드를 유실하지 않는다.
