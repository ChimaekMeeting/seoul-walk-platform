# RAW metadata

대용량 공공데이터 원본은 `.gitignore`로 제외하지만, 원본을 해석하고 적재하는 데 필요한 코드표·데이터 정의·출처 정보는 이 디렉터리에서 버전 관리한다.

## 보관 기준

- 원본 데이터셋 이름과 기준일
- 원본 컬럼 및 코드 정의
- 데이터 건수와 품질상 주의점
- 적재 시 반드시 적용해야 하는 판정 기준
- 원본 출처 또는 전달 경로

분석 과정과 V1 구현 결정은 `analysis/raw`에 별도로 기록한다.

## 파일

- `서울시_도보네트워크_데이터정의서.md`: 서울시 자치구별 도보 네트워크 공간정보 CSV의 NODE·LINK 코드와 품질 조사 결과
