# Service Layer

## 1. 소개
- 본 프로젝트의 관제탑 역할을 합니다.
- 구조는 아래와 같습니다.
```
/chat
/route
/user
```
- 추후 service 크기가 커질 경우, 더 세분화할 수 있습니다.

## 2. 코드 작성 규칙
- class로 작성합니다.
- service에서 바로 DB에 접근할 수 없습니다. DB에는 repository를 통해 접근해야 합니다.
- 각 service는 API로 연결되어야 하며, API로 연결되는 메서드의 경우 반환값을 schema에 명세해야 합니다.

## 3. 명칭 규칙
- 파일명은 {기능}_service.py로 통일합니다.

## 4. 주석 작성 규칙
- """\n~~~\n""" 형식에 맞게 작성합니다.
